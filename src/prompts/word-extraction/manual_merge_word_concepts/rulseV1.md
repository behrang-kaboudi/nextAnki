یک گروه دستی از رکوردهای `WordSense` به تو داده می‌شود. کاربر تصمیم قطعی گرفته است که تمام رکوردهای این گروه در یک `WordSense` ادغام شوند. کلمهٔ انگلیسی و `pos` تمام رکوردها پیش از ساخت این پرامپت در برنامه اعتبارسنجی شده و یکسان‌اند.

## وظیفه

تمام رکوردهای ورودی را حتماً در یک Concept واحد ادغام کن. دربارهٔ انجام یا ندادن Merge تصمیم‌گیری نکن و هیچ رکوردی را مستقل نگه ندار. خروجی خالی مجاز نیست.

از `meaning_fa`، تمام اعضای `other_meanings_fa`، `concept_explained_fa`، جمله‌های انگلیسی و ترجمه‌های فارسی جمله‌ها استفاده کن تا نتیجهٔ نهایی کامل، دقیق و بدون ازبین‌رفتن اطلاعات ورودی باشد.

## قواعد نتیجهٔ ادغام

1. رکورد دارای کمترین `id` را نگه دار.
2. `meaning_fa` همان رکورد قدیمی‌تر را بدون تغییر حفظ کن.
3. تمام `meaning_fa`ها و اعضای `other_meanings_fa` رکوردهای گروه را به ترتیب صعودی `id` گردآوری کن؛ تکراری‌ها و `meaning_fa` رکورد باقی‌مانده را حذف کن و بقیه را در `other_meanings_fa` قرار بده.
4. هیچ معنی ورودی را حذف نکن و معنی تازه‌ای تولید نکن.
5. یک `concept_explained_fa` دقیق، یکپارچه و حداکثر ۵۰ کلمه‌ای بساز که اطلاعات مفید تمام conceptهای ورودی را در یک توضیح طبیعی جمع کند.
6. تمام `sentenceIds` را به ترتیب صعودی `id` رکوردها و سپس ترتیب داخلی هر رکورد، بدون تکرار، در رکورد باقی‌مانده قرار بده.
7. تمام رکوردهای جدیدتر را با `delete: true` به رکورد قدیمی‌تر متصل کن.
8. هر `id` ورودی را دقیقاً یک بار برگردان و هیچ `id` دیگری اضافه نکن.
9. ابتدا رکورد باقی‌مانده و سپس رکوردهای حذف‌شونده را به ترتیب صعودی `id` برگردان.

## ساختار خروجی

رکورد باقی‌مانده:

```json
{
  "id": 101,
  "word": "example",
  "meaning_fa": "معنی اصلی رکورد قدیمی‌تر",
  "other_meanings_fa": ["تمام معنی‌های دیگر بدون تکرار"],
  "concept_explained_fa": "توضیح دقیق و یکپارچهٔ مفهوم نهایی",
  "sentenceIds": [1, 2, 3],
  "delete": false,
  "mergedRecordIds": [205],
  "mergedIntoId": null
}
```

هر رکورد حذف‌شونده:

```json
{
  "id": 205,
  "delete": true,
  "mergedIntoId": 101
}
```

فقط آرایهٔ JSON نهایی را برگردان. هیچ توضیح، Markdown یا متن دیگری ننویس. پیش از خروجی کنترل کن که تمام رکوردها ادغام شده‌اند، همهٔ معنی‌ها و جمله‌ها حفظ شده‌اند، قدیمی‌ترین رکورد باقی مانده، concept نهایی دقیق و حداکثر ۵۰ کلمه است و خروجی خالی نیست.
