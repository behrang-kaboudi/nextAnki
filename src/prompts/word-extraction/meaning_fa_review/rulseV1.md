هر رکورد یک مفهوم مشخص از یک کلمهٔ انگلیسی و مجموعه‌ای از جمله‌های مرتبط با همان مفهوم را نشان می‌دهد. تمام رکوردها را با مقایسهٔ `base_form`، `meaning_fa`، `other_meanings_fa`، `pos`، `concept_explained_fa` و آرایهٔ `sentences` بررسی کن.

فقط رکوردهایی را برگردان که به اصلاح معنی یا حذف یک جملهٔ نامرتبط نیاز دارند. اگر همهٔ رکوردها صحیح‌اند، فقط `[]` برگردان.

## ساختار ورودی

```json
[
  {
    "id": 1,
    "base_form": "word",
    "meaning_fa": "معنی اصلی",
    "other_meanings_fa": ["معنی جایگزین"],
    "pos": "نقش دستوری",
    "concept_explained_fa": "توضیح مفهوم و کاربرد این رکورد",
    "sentences": [
      {
        "id": 10,
        "sentence_en": "An English example sentence.",
        "sentence_en_meaning_fa": "ترجمهٔ فارسی جمله"
      }
    ]
  }
]
```

آرایهٔ `sentences` ممکن است خالی یا شامل چند جمله باشد. تمام جمله‌ها را در کنار هم بررسی کن؛ هر جمله یک نمونهٔ کاربرد برای همان مفهوم WordSense است.

## تشخیص مفهوم و کاربرد

- `pos` و `concept_explained_fa` زمینه‌ای برای فهم نقش و مفهوم موردنظر هستند، اما حقیقت قطعی نیستند؛ آن‌ها را با معنی‌ها و جمله‌ها تطبیق بده.
- از مجموعهٔ جمله‌های معتبر برای تشخیص معنی لغوی، نقش دستوری، ساختار کاربردی، گذرا یا ناگذر بودن فعل و عبارت‌های چندکلمه‌ای استفاده کن.
- وجود چند جملهٔ متفاوت طبیعی است. جمله را فقط به دلیل تفاوت موضوع، زمان، فاعل یا سبک حذف نکن.
- معنی نهایی باید مفهوم مشترک جمله‌های معتبر را بیان کند، نه ترجمهٔ وابسته به تنها یک جمله.

## بررسی جمله‌ها

برای هر عضو `sentences` بررسی کن که `base_form` واقعاً با همان مفهوم، نقش دستوری و الگوی کاربردی این رکورد استفاده شده باشد.

یک جمله نامعتبر است اگر:

- کلمه از نظر معنایی به مفهوم دیگری تعلق داشته باشد؛
- نقش دستوری یا ساختار گرامری آن با این رکورد متفاوت باشد؛
- حرف اضافه، متمم، گذرایی یا ساختار ثابت آن اشتباه باشد؛
- کلمه به‌اشتباه بخشی از یک phrasal verb، idiom، compound یا fixed expression دیگر در نظر گرفته شده باشد؛
- کاربرد کلمه آشکارا نادرست یا نامنسجم باشد.

صرفاً به این دلیل که جملهٔ دیگری طبیعی‌تر است، جمله را نامعتبر اعلام نکن. فقط شناسهٔ جمله‌های واقعاً نامرتبط یا نادرست را در `invalid_sentence_ids` قرار بده. متن جمله را بازنویسی نکن.

## قواعد `meaning_fa`

`meaning_fa` باید:

- مستقیم‌ترین، طبیعی‌ترین، رایج‌ترین و دقیق‌ترین معادل فارسی برای مفهوم مشترک جمله‌های معتبر باشد؛
- به‌صورت مستقل معادل کلمه یا عبارت انگلیسی باشد، نه ترجمهٔ کامل یک جمله؛
- کوتاه و فرهنگ‌لغتی باشد و تا حد طبیعی نقش دستوری را حفظ کند؛
- برای جمله‌های دیگری که همین مفهوم را دارند نیز معتبر بماند.

تعریف یا توضیح را جای ترجمه قرار نده. صرفاً به این علت که ترجمهٔ فعلی قابل فهم است آن را حفظ نکن؛ ترجمه‌های تحت‌اللفظی، ترکیب‌های غیرطبیعی و صورت‌های دستوری نامناسب را اصلاح کن.

نمونه‌ها:

- `dizzy` ← «دچار سرگیجه» یا «سرگیجه‌دار»، نه فقط «سرگیجه»
- `collision` ← «تصادف» یا «برخورد»، نه «تصادف کردن»
- `quantify` ← «کمّی کردن»، نه «کمیت»
- فعل انگلیسی معمولاً با صورت مصدری فارسی مانند «کردن»، «شدن» یا «بودن» برگردانده شود.

## قواعد `other_meanings_fa`

قواعد مشترک این فیلد در فایل `other_meanings_fa/rulseV1.md` بعد از این پرامپت ارائه می‌شود. آن قواعد را هم برای اصلاح مقادیر موجود و هم برای تولید فعال معادل‌های مفیدِ جاافتاده اجرا کن، حتی اگر آرایهٔ فعلی خالی باشد.

## چه زمانی رکورد را برگردانی؟

فقط وقتی حداقل یکی از این موارد وجود دارد:

1. `meaning_fa` یا `other_meanings_fa` نیازمند اصلاح معنادار است؛
2. یک معادل رایج و مهم برای همین مفهوم جا افتاده است؛
3. یک یا چند جمله به مفهوم یا کاربرد این رکورد تعلق ندارند.

رکورد صحیح را برنگردان. رکورد را صرفاً برای تغییر ترتیب معانی، نشانه‌گذاری یا تفاوت نگارشی قابل قبول برنگردان.

## ساختار خروجی

اگر فقط معنی‌ها باید اصلاح شوند:

```json
[
  {
    "id": 1,
    "meaning_fa": "معنی اصلی اصلاح‌شده",
    "other_meanings_fa": ["معنی جایگزین مفید"]
  }
]
```

اگر فقط جمله‌های نامرتبط باید حذف شوند:

```json
[
  {
    "id": 1,
    "invalid_sentence_ids": [10, 12]
  }
]
```

اگر هر دو نوع اصلاح لازم است:

```json
[
  {
    "id": 1,
    "meaning_fa": "معنی اصلی اصلاح‌شده",
    "other_meanings_fa": ["معنی جایگزین مفید"],
    "invalid_sentence_ids": [12]
  }
]
```

## قوانین قطعی خروجی

- هر `id` مربوط به WordSense را بدون تغییر حفظ کن و حداکثر یک بار برگردان.
- در `invalid_sentence_ids` فقط `id`هایی را قرار بده که در آرایهٔ `sentences` همان رکورد وجود دارند.
- شناسهٔ جملهٔ معتبر را حذف نکن و شناسهٔ جدید نساز.
- `pos`، `concept_explained_fa`، `base_form` یا متن جمله‌ها را در خروجی تکرار نکن.
- برای اصلاح معنی، `meaning_fa` و `other_meanings_fa` را همیشه با هم برگردان.
- اگر اصلاح جمله‌ای وجود ندارد، `invalid_sentence_ids` را ننویس.
- اگر اصلاح معنی وجود ندارد، فیلدهای معنی را ننویس.
- فقط یک آرایهٔ JSON معتبر برگردان؛ Markdown، توضیح یا متن دیگری ننویس.
